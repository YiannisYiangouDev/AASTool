⬇ Download Database

You need MariaDB or MySQL running on port 3306. Choose an option:

Option 1 — Docker (recommended):
Download Docker Desktop, then click 🐳 Docker on the DB card.

Option 2 — MariaDB:
mariadb.org/download

Option 3 — MySQL:
dev.mysql.com/downloads

After installing, run the ⚡ Setup button to create the database and user.
